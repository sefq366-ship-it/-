# NFT Inline Bot — токен внутри main.py

1. Открой `main.py` и замени строку
   `BOT_TOKEN = "ВСТАВЬ_СЮДА_НОВЫЙ_ТОКЕН"`
   на свой НОВЫЙ токен.
2. Старый токен, который отправлялся в чат, сначала отзови в @BotFather через `/revoke`.
3. Загрузи `main.py` и `requirements.txt` на Bothost.
4. Укажи команду запуска `python main.py`.
5. Установи зависимости из `requirements.txt`.
6. В @BotFather выполни `/setinline`, выбери бота и задай placeholder.
7. В личном чате с ботом отправь `/start`, затем ссылку `https://t.me/nft/astralshard-1`.
8. После ответа «Готово» найди NFT в чате через `@ИмяБота` или `@ИмяБота astralshard-1`.

Администратор в коде задан как `1012040843`.

База `nfts.sqlite3` создаётся рядом с `main.py`. Если Bothost пересоздаёт контейнер/папку приложения при деплое, используй постоянное хранилище и измени `DB_PATH` на его путь. Изменение токена в коде само по себе не должно создавать новые файлы, но повторное развёртывание на хостинге может пересоздать рабочую папку.

Эта версия возвращает статичную JPG-миниатюру Fragment и подпись с характеристиками. Движущийся GIF/MP4 ещё не реализован.
